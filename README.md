# QuikCli

QuikCli is a header-only opinionated command line interface builder for modern C++

## Table of Contents

- [Use Case](#use-case)
- [Design](#design)
- [example](#example)

## Design

This library is heavily inspired by OCaml's [Core.Command](https://ocaml.org/p/core/v0.14.1/doc/core/Core/Command/index.html), where I found the ergonomics and type composition and safety to be quite nice.
